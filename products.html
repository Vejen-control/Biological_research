MODULAR RESEARCH PLATFORM

From Experimental Discovery to Controlled Deployment

Aurelia BioSystems combines automated experimentation, precision imaging, environmental control and autonomous growth chambers into one integrated research workflow.

One Platform. Multiple Experimental Tools.

The platform was developed as a coherent system rather than a collection of independent laboratory instruments. Growth conditions can first be explored experimentally, measured automatically and compared. Once suitable conditions have been identified, the same environmental parameters can be transferred to independent controlled-growth modules.

01 — DISCOVERY

Automated Seed Phenotyping Station

The experimental station allows multiple seeds or biological samples to be exposed to individually defined (light wavelength) conditions.A motorised conveyor periodically presents each sample to an imaging system. Nanometric screws are used to adjust the conveyor under the microscope. Further the camera is recognising the sample automatically.

Images are captured automatically throughout the experiment, creating a complete visual record of development.


Light intensity and wavelength can be controlled for individual samples, allowing different illumination conditions to be tested within the same experiment. Pre-Set temperature is controlled constantly. Day and night cycles can also be reproduced automatically.

Experimental Capabilities

  • Multiple samples monitored simultaneously
  • Programmable imaging intervals
  • Individual light intensity control
  • Individual wavelength control
  • Programmable day/night cycles
  • Automatic image acquisition
  • Growth measurement through image processing
  • Time-lapse video generation
  • Long-term experiment recording

The experiments are very light sensitive. This is the reason why the equipment is enclosed in a non transparent box. It has to be closed during the experiments.

The carusel with the samples is separated from the light source for easy access. Samples are installed manually in designated pockets

03 — HIGH RESOLUTION OBSERVATION

Automated Microscope Imaging Platform

For experiments requiring higher magnification, a CNC-positioned microscope system allows multiple areas of interest to be monitored automatically. Researchers select positions on the XY working area and focus the microscope using the Z axis. The system subsequently revisits each position according to the experimental schedule.

Automated Imaging

  • Motorised X positioning
  • Motorised Y positioning
  • Motorised Z focus
  • Multiple areas of interest
  • Scheduled position revisiting
  • Automatic image storage
  • Time-series comparison
  • Long-duration observation


After each image processing cycle the sample is repositioned against high intensity light (not suitable for obtaining good images). The enclosure is visible from the back of the motorised table. At this position the sample is completely protected from the environmentdue to a flap which closes the opening of the microscope during sampling. Also the nutrition and water supply pipe is visible on the left side of the picture. The pump supplies this liquid in very small quantities using as sensor resistive measurement of the media with the sample. Due to constant current in the media the water is evaporating very fast and needs to be replanished in order to support the biological sample.

The control box of the system is supporting the temperature the current trough the sample and water supply while the PC is conducting the real measurement.

All parameters can be set vis PC using internal USB communication between the control box and the PC software. Image processing is directly conducted on the obtained pictures in order to monitor the parameters of the sample in real time. The statistic is updated on every cycle during the experiment while the image processing strategy can be selected, modified or changed even during the experiment. Multiple areas of interest can be selected in a cycle.

This experiment used single selected current value trough the sample. If the experiment requires parallelism different chambers (pockets) can be machined with proportinal current flow trough them. The system will handle this just by selecting multiple areas of interest.

Object Tracking

Image processing can identify biological objects using colour and shape. If the sample moves slowly during an experiment, the area of interest can be adjusted to follow the object.

It has been found that the following image processing pipeline is working very well with biological samples. The image is subjected to colour filtering with specific radius. Then the pixels are converted to black and white and area of interest is calculated as pixels. This allows to control the smaple size and state during experimentation. Since the microscope has its own light source the result is stable calculation of the sample size (surface).

To facilitate the image processing it is advisable to conduct the experiment in environment which is optically different than the colour of the sample you will measure. The image clearly shows the image proceesing steps. All parameters to obtain good results are exposed in the software.

Controlled Optical Experiments

Because illumination is controlled independently, the imaging platform can be adapted for specialist optical experiments including low-light observations, bioluminescence studies and controlled UV illumination.

The light source used to expose the sample is different than the light source during the image processing. In this sense it is possible to make experiments with non visible light like deep IR or UV.

Here we can see experiment showing the effect of long time UV exposure. The deep UV light container is on the left ( LEDs hardly visible) while the control sample is on the right (visual light). A peristaltic pump samples biological material for optical analysis in pre-set period of time.

Specially designed peristaltic pump controller was developped in order to automate experiments which require long time (few weeks).

05 — REMOTE RESEARCH

Online Monitoring & Research Dashboard

The physical laboratory is connected to an online software environment developed in ASP.NET and C#. Authorised users can access experiments remotely and view information according to their assigned permissions.



Remote Monitoring

  • Browser-based access
  • Live experimental information
  • Environmental measurements
  • Camera images
  • Experimental history
  • Remote supervision

Remotely monitoring data from a pot. This requires simply connection to a local Wi-Fi server and point to the right menu.

Most of the equipmenent we developped is Wi-Fi capable. This serves multiple purposes: allows remote monitoring while the hardware is in difficult to reach places or connecting the unit to more advanced system. In order to achieve the second goal we have created OTADA (Over The Air Data Analysis) system. This is ASP software which can collect, analyse and amalgamate huge amount of data into logical conclusion using all the data, past perioods or data, goal parameters etc. The package was created to allow AI to access the data and make automatic analysis.

User Permissions

Different users can be given different levels of access, allowing researchers, technicians, project managers and external collaborators to see only the information relevant to their role.

OTADA requires each user to have one of the three permitted login credentials ( User, Engineer or Admin)

Depending on the permissions data can be plotted in real time or for past period. It can be compared or analysed.

The bigest difference between a local system and distributed server is the amount of data it can handle and the complexity of the analysis it can perform. WHile a local embedded system can handle 10-20 parameters, OTADA can deal with millions and on top of it many local or online AI models can work simultaneously on the data.

Distributed Experiments

Multiple growth modules can communicate with the same monitoring environment, allowing experiments to be distributed between different physical locations.

Research Data

Images, environmental measurements and experimental parameters can be stored together, producing structured datasets for later scientific analysis.
